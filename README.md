# 星灯りの人形ギルド — テストプレイ版 v0.1.1

QuQi の新作ゲームの、**第1段階の試作**(固定の戦闘練習)をブラウザで遊べるようにしたものです。完成品ではありません。

## 遊ぶ

**https://reivup.github.io/hoshiakari-playtest/**

- PCのブラウザ(Chrome / Edge / Firefox)で開いてください。スマートフォンには対応していません。
- 最初の読み込みに少し時間がかかります(約45MB)。

- 言語は「設定」で日本語 / English / 简体中文 を切り替えられます。簡体字は一部の字が表示されないことがあります。

## 何をするゲームか

4人の魔法人形それぞれの「記憶盤」(5×4マス)に、形と大きさのある「行動札」を収めて、戦いの作戦を組みます。
盤はマスが限られているので、何を入れて何を外すかが作戦づくりの中心です。

1. 「はじめから」で行動図の編集画面へ。上の顔で4人を切り替えます。
2. 左の「行動札」から札を選び、盤の置きたい場所をクリックして置きます(置く前に緑・赤の予告が出ます)。
3. 札の右の丸から、つなぎ先の札の左の丸までドラッグして線をつなぎます。
4. 「練習開始」で戦闘へ。人形が動いた理由が、右の「行動理由」に出ます。
5. 負けたら「編集へ」で札や数値を一つ直して、「再試行」で同じ条件からやり直せます。

最初の作戦のままだと、あと一歩のところで負けます。**何を直すと勝てるでしょうか。**

## 操作

- マウス: 札の一覧をクリックして盤へ置く / 札をドラッグして動かす / 出口の丸から入口の丸へドラッグして配線 / 右クリックで札メニュー
- キーボード: 矢印キーで選択、Enterで決定、Escで戻る・一時停止、A 札を追加、C 配線、Z 元に戻す、Q / E 人の切り替え。戦闘では N 一手、P 通常/倍速/停止、R 再試行
- コントローラー: 十字キーで選択、A 決定、B 戻る、Y 札を追加、X 配線、LB / RB 人の切り替え、Start 一時停止
- 操作の一覧は、Escで開く「一時停止」→「操作説明」にもあります。

## 教えてほしいこと

- 何を外したら、欲しい札が入ると気づきましたか?
- 札を置く・つなぐ操作で、迷った所はありますか?
- 負けた理由(右の「行動理由」)は、読んで分かりましたか?
- 直した結果が変わった理由を、自分の言葉で説明できましたか?
